# CreditGuard

CreditGuard is a machine learning-based credit card fraud
detection platform.

## Objectives

- Detect fraudulent credit card transactions.
- Calculate transaction risk scores.
- Generate fraud alerts.
- Monitor transactions through an analytics dashboard.

## Technology Stack

- Python
- Scikit-learn
- XGBoost
- FastAPI
- PostgreSQL
- React
